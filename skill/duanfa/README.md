# 断法原文库

`daquan.json` 摘自《六壬大全》四库全书本，据[维基文库](https://zh.wikisource.org/wiki/六壬大全)标点录文，
由 `core/tools/gen_duanfa.py` 切分生成：九宗门课体（卷七）、十二神与十二将（卷二），每条截短到一千余字。

古籍原文属公有领域；标点为维基文库志愿者所加，按 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 授权。
因此本目录下的 `daquan.json` 单独按 CC BY-SA 4.0 发布，不适用仓库的 MIT 许可。

网页版与官方 skill 按课盘从这里取原文：本课课体、三传所见十二神、三传所乘天将，附在提示词后面，供 AI 断课时引据。
