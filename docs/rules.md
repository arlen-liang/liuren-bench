# 规则待核清单

引擎里的每条规则都是按通行口诀写的，还没拿古籍逐条对过。这份清单列出实现时做的每一个选择、它影响多少课，以及目前的证据。古籍校验集建好以后，逐条改成"已核"并注明书目卷次。

"影响课数"指在 720 课里，换一种做法三传会变的课数。

## 结构性检验（已通过，不依赖流派）

- 720 课平移不变性：同一日干支、同一"月将−占时"相对位，四课三传课体完全相同
- 伏吟 60 课、返吟 60 课
- 返吟无克只有丁丑、丁未、己丑、己未、辛丑、辛未六日，与推算一致

## 与 kinliuren 的差分

kinliuren 是现有的开源六壬排盘库（MIT）。拿它和本引擎逐课比对三传，720 课里：

- 506 课结果一致
- 172 课 kinliuren 的结果会随月将、占时的绝对位置变，其中一个与本引擎相同。按 720 课的定义，同一课的结果不该变，这部分应属它的问题
- 42 课完全不一致。其中 8 课按贼克优先、比用的规则可以直接判定，另有 9 课方向上较有把握，其余 25 课落在上表的待核规则里，等古籍来裁

复现方法见 `core/tools/diff_kinliuren.py`。
