# 规则核对清单

引擎以《六壬大全》（四库全书本，据 zh.wikisource 录文）为准。这份清单列出每条规则的实现、核对状态和依据。"影响课数"指在 720 课里，换一种做法三传（或天将）会变的课数。

对应的测试在 `core/tests/test_daquan.py`，每条都注了卷次和原文要点。

## 结构性检验（不依赖流派）

- 720 课平移不变性：同一日干支、同一"月将−占时"相对位，四课三传课体完全相同
- 伏吟 60 课、返吟 60 课

## 已核

| 规则 | 本引擎的做法 | 依据 |
|---|---|---|
| 贼克、比用 | 先取下贼上，无则上克下；多个取与日干阴阳相同者 | 卷一 入手法"取课先从下贼呼""阳日用阳阴用阴" |
| 涉害数克 | 从所临之位前行至本家，所临之位与本家不计，沿途地支与所寄之干都计 | 卷七 正月丁卯日丑时亥将例，原书附课盘，逐位列出"辰、戊、未、己、戌土位五重"。此条修正后，6 课三传随之改变 |
| 涉害等深 | 取临孟者，次取临仲者；再等，阳日取干上神，阴日取支上神 | 卷一"孟深仲浅季当休，复等柔辰刚日宜" |
| 遥克 | 先取神克日（蒿矢），无则日克神（弹射）；多个取与日干阴阳相同者 | 卷一"先取神遥克其日，如无方取日来遥……择与日干比者用" |
| 八专与遥克的先后 | 八专日无上下克，直接走八专，不看遥克（影响 7 课） | 卷一 八专法小注"论克不论遥" |
| 八专取传 | 阳日干上神顺数三位（连本位数），阴日第四课上神逆数三位；中末俱取干上神 | 卷一"阳日日阳顺行三连本位数，阴日辰阴逆三位，中末总向日上眠" |
| 昴星 | 阳日取地盘酉上神，中支上、末干上；阴日取天盘酉所临，中干上、末支上 | 卷一"阳仰阴俯酉位中……刚日先辰而后日，柔日先日而后辰"；补论"凡昴星止十六课"，本引擎恰为 16 课 |
| 别责 | 阳日取干合之干寄宫上神；阴日取日支三合的下一位；中末俱取干上神 | 卷一"刚日干合上头神，柔日支前三合取"，小注逐一列出九课，与本引擎算出的九课逐课相同 |
| 伏吟 | 有克取克；无克阳日取干上、阴日取支上；中取初之刑，末取中之刑；初传自刑则中传取干支上神中的另一个；中传自刑则末传取冲 | 卷一"伏吟有克还为用，无克刚干柔取辰……若也自刑为发用，次传颠倒日辰并。次传更复自刑者，冲取末传不论刑"；课经"乙癸有克法不同"，本引擎有克者恰为乙、癸日 |
| 返吟 | 有克照贼克取；无克（井栏射）初取日支驿马，中取支上神，末取干上神 | 卷一"若知六日该无克，丑未同干丁己辛。丑日登明未太乙"，六日与本引擎一致 |
| 贵人口诀 | 默认"甲牛"版：甲戊庚牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，六辛逢马虎 | 卷一、卷十一、卷十二共 5 条注例写明了天将，全合"甲牛"版；其中壬子日夜贵、壬辰壬戌返吟夜占两条，"甲羊"版对不上。四库提要亦称此书"所取天乙尚沿俗例" |

## 时间层

| 规则 | 本引擎的做法 | 状态 |
|---|---|---|
| 节气时刻 | 太阳视黄经过 15° 整数倍的时刻，pyephem 计算，与天文台公布时刻抽查一致 | 天文计算，无争议 |
| 月将 | 中气当刻换将：雨水后亥将，春分后戌将，依次逆行 | 未核（另有中气当日换将之说） |
| 年、月 | 年以立春当刻为界，月以节当刻为界，月干按五虎遁 | 通行做法 |
| 日干支 | 按儒略日推算，以 1949-10-01 甲子、2008-08-08 庚辰等日为锚 | 无争议 |
| 子时换日 | 默认 23 点换日（子初），可切换为 0 点（子正） | 未核 |
| 占时与真太阳时 | 默认用北京时间定占时；可切换为真太阳时（经度折算 + 均时差） | 未核 |

## 与 kinliuren 的差分

kinliuren 是现有的开源六壬排盘库（MIT）。拿它和本引擎逐课比对三传，720 课里：

- 506 课一致
- 171 课 kinliuren 的结果会随月将、占时的绝对位置变，其中一个与本引擎相同。按 720 课的定义，同一课的结果不该变
- 43 课完全不一致：伏吟 9、八专 5、昴星 5、返吟 7、比用 1、涉害 16。前五类本引擎的做法与《六壬大全》口诀逐字相合；涉害 16 课本引擎依卷七的数法，候选范围一项仍待核

复现方法见 `core/tools/diff_kinliuren.py`。
